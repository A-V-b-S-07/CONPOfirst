# CONPO

## Sobre o projeto
CONPO é uma aplicação full-stack composta por backend e frontend, projetada para facilitar a vida dos pacientes e manter suas organizações para as consultas em um só lugar, tendo acesso por cadastro e login, a página home inclui uma agenda para compromissos, ficha pessoal - dados pessoais e lista de alergias complicações de saúde e tipo sanguíneo - contando também com um espaço para adicionar prescrição de remédios e exames exigidos pelos médicos.
Ela integra uma API (backend) com uma interface web (frontend), permitindo que usuários interajam com os dados de forma dinâmica, por meio de operações CRUD, autenticação e outras ações relevantes.

Linguagens usadas: **HTML**, **CSS**,  **JavaScript**.

## Funcionalidades
- Interface web para interação com dados.
- Backend via API para servir dados ao frontend  
- Recursos estáticos (imagens, ícones, etc)

- **Frontend**: HTML, CSS. 
- **Backend**: JavaScript (Node.js), MySQL
- **Comunicação**: via requisições HTTP entre frontend e backend


## Como rodar o código

1. clone o repositório
2. abra o git bash e cole o projeto -> git clone https://github.com/A-V-b-S-07/CONPOfirst.git
3. de um **cd CONPOfirst**
4. e depois acesse o backend da pasta **cd backend**
5. instale as dependências **npm install**
6. Inicie o servidor **npm start**
7. pasta principal **cd ..**
8. acesse o frontend **cd frontend**
9. instale as dependências **npm install**
10. Inicie o aplicativo no front **npm start**
